Node types

KILLED sink — candidate drops out, no brief / no publish / no ping

Connector types

Handoff — the main queued-token path between stages
Posts to — an agent writing into a Discord channel
Writes to — solid blue into a shared store
Reads from — dashed blue out of a shared store
Kill / fence — dashed red into the KILLED sink

Interactions

Click any node, arrow label, or the kill sink → opens the detail drawer (role, inputs/outputs, scripts, checklist).
Hover a stage → highlights only its own wires, dims the rest of the canvas.
Replay path → animates a token chip through the happy path or the kill/fence path, stage by stage.
Esc or click the backdrop → closes the drawer.
